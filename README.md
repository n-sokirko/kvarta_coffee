# Кварта: лендинг обжарки кофе

Русскоязычный лендинг вымышленной минской обжарки «Кварта» (тестовое задание). Три 3D-сцены на чистом WebGL: зерно → кружка, пачка → фургон → дверь. Форма заявки с проверкой белорусского номера и защитой от повторной отправки в течение 10 минут.

Опубликованная версия: https://claude.ai/artifact/KpcZ5zdz2rzUJ86qY4RPUv (доступ только владельцу).

## Что где

| Папка | Содержимое |
|---|---|
| `artifact/` | `Main.dc.html` (страница в формате Design-артефакта) и `canvas.json` |
| `gl/` | движок и сцены: `kv-gl.js` (рендерер, шейдеры), `kv-models.js` (модели), `kv-scenes.js` (хореография); `harness2.html` и `test4.html` для проверки сцен отдельно |
| `logic/` | `kv-lead.js` (маска и проверка номера, защита от повтора) и тесты `kv-lead.test.js` |
| `copy/` | текст страницы `deck-v3.json`, `apply-copy.js` (вставляет текст в страницу), `lint2.js` и правила линтера |
| `docs/` | правила текста `kvarta-copy-rules.md`, аудит и исследования текстов других обжарок |
| `assets/` | текстура зерна для бумаги |

## Как пользоваться

Проверить логику заявки:

```bash
node logic/kv-lead.test.js
```

Проверить текст линтером:

```bash
node copy/lint2.js copy/deck-v3.json copy/linter-spec.json
```

Применить текст к странице (нужна базовая `Main.dc.html`):

```bash
node copy/apply-copy.js artifact/Main.dc.html copy/deck-v3.json out.html
```

Сцены запускаются на любом статическом сервере: положить `gl/*.js` рядом с `gl/harness2.html` и открыть `harness2.html?s=pour&p=0.9`.
