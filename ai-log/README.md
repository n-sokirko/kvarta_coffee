# Лог работы с ИИ

`kvarta-session-export.zip` содержит экспорт сессии Claude Code: переписку, переписки субагентов и метаданные.

Что изменено относительно исходного экспорта:
- встроенные в переписку картинки (скриншоты в base64) заменены пометкой `[image omitted]`, чтобы уложиться в лимит 20 МБ;
- токен Telegram-бота, который пользователь вставил в чат, заменён на `[TELEGRAM-TOKEN-REDACTED]` (токен уже заменён на новый).

Текст сообщений и вызовы инструментов не менялись.
